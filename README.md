### [Primer Video](https://youtu.be/PFgjR-Wn6i8)

En este primer problema, LeetCode #148 se tiene que ordenar una lista ligada sin usar una estructura adicional como un vector. La resolví usando un merge sort para cumplir con los requisitos de tiempo O(n logn) y de espacio O(1).
